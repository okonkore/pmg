# 音符ごとの弾く強さ

## 操作と互換性

音符を選択して「音符」を開き、先頭にある「弾く強さ（音符ごと）」をスライダーまたは1〜127の整数で設定する。内蔵曲はコピーしてから編集。複数選択時に異なる値なら「異なる強さが混在」と表示し、変更した値を選択音符すべてに適用する。「標準の127に戻す」は選択した音符だけを127へ戻す。

既存の `note.velocity`（0より大きく1以下）を使い、入力値/127を保存する。新しく配置する音符は従来どおり127相当（velocity=1）。既存曲・MIDIインポートの値は保持し、新たなデータ形式や移行は導入しない。値は曲の保存・再読込・JSON・複製・Undo/Redoに含まれる。数値の空欄・0・128・非整数は拒否する。既存の小数velocityは編集しない限り維持し、画面表示だけ1〜127に丸める。

## 再生との関係

音符の強さは従来からstartSong→playへ渡されている。今回の変更はその既存機能の編集UIを明確にし、数値入力・混在表示・一括操作を加えるもの。

- Physical Guitar（弦を設定）では、演奏設定のforceN等で準備した波形を、再生時にvelocity倍する。127で既存の基準振幅、32で32/127倍。全体の音量や引く力は変更しない。音符ごとにニュートン値を新しく計算する機能ではない。
- Whole-shell/520R系は同じくgainにvelocityを渡す。
- 弦Ver2は既存のprepare処理で、最大変位制限後の最大引く力×velocityを使用する。画面鍵盤の強さ設定は曲の明示的velocityを上書きしない。
- 他の合成音源も既存の強さ経路を維持。

音色・スペクトル・非線形性が新たに変わるとは主張しない。全体設定との組み合わせや小さい強さの聞き取りやすさは音源・音量・再生環境による。
