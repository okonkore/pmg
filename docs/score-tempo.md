# 曲ごとのテンポ範囲

作業ベース: `0dbbd638bc5f8601e2dcbd62e65a7349f9377e5c`。
音響モデル・公開設定・内蔵曲の音符データは変更しない。

## 操作

1. 編集画面を開く。内蔵曲は「曲の設定・保存」からコピーする。
2. 小節番号の直下にあるテンポ行をドラッグして、小節単位で範囲を選ぶ。タップだけなら1小節。通常の小節番号行は引き続き再生位置移動と横ピンチに使う。
3. 到達BPMを指定する。直前のBPMより低ければ減速、高ければ加速。範囲後は到達BPMの維持または基本BPMへの即時復帰を選ぶ。
4. 「曲に保存」で自動保存。範囲のタップ、または「テンポ変化」の一覧から編集・削除できる。狭い範囲や画面外の範囲は一覧と数値入力を使う。
5. 開始・終了の小節位置は小数入力可能。1は第1小節先頭、2は第2小節先頭、1.5は第1小節中央。通常方式の最小幅は4分音符0.25拍。重なり不可、隣接可。キャンセルや2本指では範囲を確定しない。

テンポ編集は曲のUndo/Redo、複製、JSON書出・読込に含まれる。基本BPM・拍子を変更しても、保存した到達BPMと絶対拍位置は固定。テンポ範囲の終端まで曲の長さに含む。最大4096拍、1024範囲、到達BPM5〜600。基本BPMの既存20〜300制限は維持。

## 互換性

`tempoChanges` がない既存曲は以前の共通リタルダンドを使い続ける。共通コントロールは再生設定から編集画面の「テンポ変化」内の折りたたみへ移動した。`pmg.playback.v1` の値は削除しない。

「以前の設定を曲に取り込む」は現在の曲長・BPM・拍子から旧設定を展開する。拍の時間を線形変化する旧カーブと終端で基本BPMに戻る動作を保存する。極端に短い旧範囲も旧方式では正の長さなら許す。取り込み後の曲は他端末でも同じ設定で再生できる。取り込み後に基本BPMを変えても、到達BPMは取り込み時の絶対値を保つ。

明示的な `tempoChanges: []` は共通設定を無視した一定テンポ。新規作成曲はこれを初期値とする。既存曲で最初の独自範囲を保存すると共通設定を置き換える（画面に明記）。元に戻すと未移行状態にも戻れる。

保存・JSON出力のversionは2。version1と2を読み込み、読んだだけでは保存を書き換えない。保存キーは既存の `pmg.songs.v1` を保持し、他タブとの更新競合チェックも保持。旧アプリはversion2を拒否するため、古いアプリで編集するとテンポ範囲だけが消えることはない。旧版へのロールバック時にはversion2の読込対応が必要。

## 計算

`tempoChanges: [{id,startBeat,endBeat,targetBpm,after:'hold'|'base',curve:'bpm'|'period'}]`。
位置は4分音符単位、開始BPMは前の範囲後の状態から導出。通常方式はBPMを拍に対して線形変化させ、`60 / BPM(beat)` の解析積分で秒に変換する。旧方式は秒/拍を線形変化して二次式で積分する。境界で時刻は連続。`after:base` のBPMのみ意図的に不連続。

イベントの開始と終了を同じ時間写像で変換する。途中再生は曲頭からの累積時刻を差し引き、持続音は残り区間を再発音する既存動作を維持。ループは指定カーソルから曲末を繰り返し、各周回のBPMをカーソル位置の値へ戻す。ストラムは実時間msのまま。プレイヘッドと再生中BPM表示も同じ写像を使用する。曲の長さ表示は曲保存範囲を含み、未移行曲は共通リタルダンドを除く旨を表示。

## UI V2の再生開始エラー修正

公開コミット4306e03で、`?ui=v2` の画面組み替えが `seq-current-bpm` を含む旧ツールバーを削除していた。再生開始時の `setPosition()` が存在しない表示要素のtextContentを設定して例外になった。Chromiumでも `音声を開始できませんでした: Cannot set properties of null (setting 'textContent')` を再現した。テンポボタンも編集ツールのreplaceChildrenから漏れていた。

修正ではBPM表示を再生位置とともにV2ドックへ移し、テンポボタンもV2ツールバーへ移す。保存・時間計算・音響モデルは変更しない。V2モジュールとCSS、その呼び出し側のキャッシュキーを更新。

`test_tempo_v2_browser.cjs` が従来UI/V2双方でテンポ編集画面、曲頭・途中ループ再生の非ゼロ波形、BPM表示、エラーの不在、保存データの不変性、モバイル幅を確認する。`test_ui_v2.cjs` のモジュール読込制御は新しいクエリ付きURLに対応させ、古い固定曲数を実カタログ数との比較に変更した。
