# 係数計算の共通化とC++/WASM移植（2026-10-29）

依頼：音源準備の共通計算を再利用し、重い係数計算もWASMで行う。
実装言語はC++17（Rust限定ではない）。WASI SDK 34.0、Eigen 3.4.0を使用。
コンパイラは一時作業フォルダに取得し、利用端末へは約272KiBのWASMだけを配る。

共通化：ボディの固定行列・端点写像・差分・単位質量の積を初期化時に保持。
各弦の断面特性・開放張力・合計張力は同じ設定では一度だけ計算。
弦長や音程によって変わる連成行列と固有問題は音ごとに解く。
設定変更は共有コンテキストを更新する。既存PCMキャッシュは互換として残す。

C++へ移した処理：行列組立、Cholesky/LU分解、非線形静的初期状態、
実固有値・固有ベクトル、元の全放射モードとのSylvester合成、係数バイナリ出力。
設定の検証と音程から弦長への変換は小さなJSの共有コンテキストに残す。
波形生成は従来のFloat64 SIMD WASMをそのまま使い、最大15秒を維持。
近似の追加、EQ、録音フィット、減衰係数の変更はない。

検証：全88音でC++係数生成が成功。E2、D3（4弦/6弦）、C4、E4、
A0、C8、44.1/48/96kHzの9条件で従来JS版と波形を比較。
相対L2差は最大0.0421%（一部は0.2秒、E2/D3は3秒）。
初期張力変化は1e-9N未満の差。固有ベクトルの基底が変わるため、
既存3%疎化の選択と浮動小数点誤差による微小差がある。
係数計算時間は同一プロセスで従来版の約4.3〜6.2倍速。
この倍率には15秒波形の計算・保存を含まない。
係数WASMメモリの高水位は約95.4MiBで全音域の反復後も増加しなかった。

公開フォルダの `coefficients-validation.json` に各条件の数値と時間を記録。
`test_guitar_wasm_coefficients.cjs` が比較・設定変更・全音域を再現する。
モバイル幅の実ブラウザでも、C++版の係数を使って音源準備・鍵盤・曲再生・
キャッシュ再利用・15秒制限・中止が成功し、旧JS線形代数が読み込まれないことを確認。
iPhone実機の速度・メモリ計測は未実施。
