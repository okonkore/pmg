# 端末で選べる準備並列数（2026-10-29）

ユーザーがiPhoneで並列数を変えて試せるよう、公開アプリの演奏設定とメイン画面に
1〜4並列の指定を追加。初期値1。端末に選択を保存し、物理条件・音色キャッシュの
署名には含めない。通常の音源準備は、保存済みを再利用して不足分だけを並列計算する。

同じ4音（E2/A2/D3/E4）の速度計測ボタンも追加。既存キャッシュを使わず計算し、
音源や設定を置き換えず結果を破棄する。各並列数の最新秒数を端末に保存して表示。
物理設定またはサンプルレートが変われば比較記録を新しい条件に切り替える。
並列数以外を揃えて1→2→3→4と比較できる。3/4はメモリ増加の注意を表示する。

進捗は全レーンの音名・計算段階・完了数を表示。音ごとに保存するため中止後も再開可。
一部のレーンの失敗時は他のWorkerも全て停止し、以前の演奏可能なバンクは維持。
速度計測でキャンセルしても、直前の結果と演奏設定・保存済み波形は維持する。

検証：実IndexedDBと制御用Workerによる1〜4並列の同時進行、キャッシュ再利用、
速度計測の隔離、途中失敗時の全停止、部分再開、中止時の全停止が成功。
モバイル幅のEdgeで並列数の保存/同期、弦セット管理、キャンセルを確認。
実際のWASM/Workerでも2並列準備→鍵盤/曲再生→キャッシュ再利用、4並列計測、
4Worker起動後の中止、設定が変わらないことを確認した。
iPhone実機では未測定。iPhone本人のブラウザで計測するための機能として提供する。
