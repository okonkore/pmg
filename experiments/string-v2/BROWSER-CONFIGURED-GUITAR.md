# 端末内で準備する設定可能な物理ギター（2026-10-29）

ユーザーの選択：iPhoneでも準備・演奏し、サーバーでの音声計算を使わず、
物理モデルを軽量化する。各弦を設定してから波形を準備し、既存アプリの鍵盤・
シーケンサーで演奏する方式を採用。録音への倍音フィットは行っていない。

公開実装は `synth-demo/instruments/configured-guitar/` と
`configured-guitar-app.js`。従来の固定3音の完全係数版は残す。
入力は6弦の単線/巻弦、直径、密度、ヤング率、内部損失、芯/巻線の構造、
弦長、弾く位置、力。標準開放調弦から張力を計算する。

完全系の胴抽出では、弦の相対座標513..634のみを除去し、支持座標635,636は
必ず残した。支持座標を落とした試案は不採用。端点の静的変位・力方向を保ち、
エネルギー直交射影で胴の機械移動度を256状態へ縮約した。放射の1704モードは
削除せず、Sylvester変換で小さな固有問題に合成する。圧力の録音合わせや
ノッチ処理は使用しない。候補64/96/128/192状態は誤差を理由に採用しなかった。

実行時は module Worker + ml-matrix 6.12.1 + 既存Float64 WASM。
各音のPCM24をIndexedDBへ保存（振幅を戻す可逆な符号化スケールを付記）。
AudioBufferのLRUは64 MiB、最大12発音。音源準備はメイン/音声スレッドの外。
中止時も完了済みの音を残す。設定を変更すると別のキャッシュとして準備する。

検算：E2、4弦開放D3、6弦10フレットD3の初期張力変化は完全系と一致。
3秒波形の相対L2誤差は2.16%,4.83%,9.79%、最初の100msは0.13%,0.27%,0.76%。
誤差には位相ずれを含む。物理エネルギーは0..3秒の検査点で正かつ単調減少。
詳細は公開フォルダの `validation.json`。

全88音の物性条件計算、15音の弦切替境界/最低最高音で固有問題と波形を確認。
単線/巻弦の変更、44.1/48/96kHzの低音・高音も確認した。
Windows Edge（390×844、タッチ条件）で6本の設定入力、巻線径連動、
キャンセル、実Workerでの2音準備、鍵盤の非ゼロ出力、曲再生、
キャッシュ再利用、中止・設定保存を確認。iPhone実機の計測は未実施。

制約：縮約版のため完全系と同一波形ではない。音ごとに独立しており弦間共鳴や
指の接触は含まない。強弱は生成後の音量であり、物理的な引く力変更は再準備。
モデルの胴形状は固定で、任意物性への変更時に再メッシュはしない。
長い尾は最大50秒まで生成し、末尾フェードは加えない。準備には時間がかかる。
