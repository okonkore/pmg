# Automatic TAB preview / print candidate

Original candidate base: `bc15963b3d1ce5d0624ad5c504114480d94df63f`, prepared in `/workspace/pmg-tab`. User-approved release integrated in `/workspace/pmg-tab-release` on `4a88a8b25d18c8f453402fa68d4f570281eba387`, preserving the depth comparison page, WAV assets and Pages workflow.

Current normalized song notes contain pitch, beat, duration, velocity and ID, not authoritative string/fret/finger/voice assignments. MIDI import likewise retains note timing, not guitar fingering. The configured synthesis engine independently selects a string for each pitch and can simulate below-open pitches by changing tension; it does not supply a playable polyphonic arrangement. This candidate does not change or reuse that synthesis policy as fingering evidence.

TAB planner: standard E2 A2 D3 G3 B3 E4, frets 0–19, unless validated song source metadata supplies required tuning. Such tuning is used and prominently labeled for TAB only, never applied to the instrument. A bounded 24-state search considers string occupancy through each full note duration, fret position movement and large simultaneous fret spans. It handles coincident and overlapping notes without assigning overlapping holds to the same string. An unassigned option preserves every event with an explicit reason rather than dropping notes. More than six simultaneous notes, below-open/high pitches and constraints caused by held notes can remain unassigned. Spans exceeding four frets are flagged. This is a heuristic automatic proposal, not original fingering or a guarantee of hand feasibility; finger count, barre, technique, capo, articulation and voice-leading intentions are not modeled.

UI: main menu and editor menu offer TAB譜・印刷, opening an internally scrolling dialog using existing Back/Forward/Escape dismissal. The current document is copied for planning; opening/closing does not rewrite song data. Opening stops playback to permit review/printing. Six rows are ordered first string at top. Mobile measures scroll horizontally with sticky string labels. Printing uses A4 and break-inside avoidance; a long measure splits after eight attack columns with a continuation heading. Browser print/PDF action is available, with no upload or external service.

Notation scope: a six-line, numeric-rhythm TAB worksheet. Horizontal attack columns are evenly spaced, not a proportional score engraving. Each column labels exact underlying quarter-beat position (zero-based within its measure); attack cells show fret plus full duration in brackets. Display numbers use simple fractions where numerically equivalent and an explicit ≈ for other rounded displays; source data is never quantized. Continuation arrows represent held notes at later columns/measures, not newly plucked notes. Full-piece silence intervals are listed per measure. Note-off can be read from onset plus duration even when there is no separate release column. Conventional stems, beams, rest glyphs, ties, voices and fingering numbers are explicitly not engraved. Fixed meter/BPM come from the current document; unsupported changing MIDI maps/SMPTE remain unsupported by the importer. No new MIDI behavior is included.

Limits: 20,000 notes and 512 measures; longer output is rejected explicitly without truncation or modifying the song. All 38 built-in selections fit and produced the same count of planned events as input notes. Source/title/license/modification strings are rendered as text and printed with the TAB; structured required tuning appears in the heading. Private imported files are not bundled. Source licenses remain distinct from application code.

Tests: tab-model.test.cjs covers six-note chords, seven-note overflow, sustained low-string conflicts, out-of-range pitches, fractional onsets, rests, cross-bar holds, required tuning, 1,000-note long scores, limits, source immutability and a generated MIDI import. test_tab_browser.cjs covers built-in and edited/import-style documents, source preservation, script-like title text, four viewport shapes, print invocation/PDF generation, Escape/Back/Forward and unchanged document state. Original synthetic 32-bar fixture produced 12 A4 pages; final source credit/license text was confirmed by PDF text extraction and a middle page visually inspected.
