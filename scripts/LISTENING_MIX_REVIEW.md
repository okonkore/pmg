## Audio routing

Existing SPACE is a feedback delay and remains in the secondary tone dialog, with its original preset values. It is not relabeled as reverb. Physical body damping and preparation models are untouched.

Normal instruments keep their existing `.65` bus, delay, default `.22` reference level and compressor (threshold −16 dB, ratio 5). The physical-string worklet retains its original `.2 × .22` reference gain and bypass of that compressor. Both paths then join the new room stage, existing master GainNode, output peak guard and analyser/destination. The existing master now uses `slider / .22`, so its default unity output preserves the previous default signal; changing it controls dry sound and already-ringing room tails together. This intentionally makes volume adjustments linear after compression instead of changing compressor drive. No instrument gain control or cache key is duplicated.

`room-reverb.js` contains a deterministic, normalized stereo convolution impulse (1.4 seconds), created locally. Default amount 0 disconnects the convolver's input and uses unity dry gain. Amount 0–100% maps to a conservative 0–35% wet linear crossfade; dry/wet changes ramp for 30 ms. Moving back to zero fades pending room output while disconnecting new sends. Master changes use the existing 15 ms target smoothing. The default dry output bypasses peak protection completely, preserving amplitude and headroom even above .9. Reverb use or volume above .22 crossfades to a protected branch over 30 ms before raising volume/changing wet amount. Returning to dry/reference level allows the master to settle for 120 ms before crossfading protection out. Complementary branch gains still pass through the same master exactly once. The protected branch is identity below magnitude .9 and softly bounds boosted peaks below .98; it has no oversampling delay and does not change physical parameters.

Stop/navigation replace and disconnect the convolution node, immediately discarding its history without rebuilding the impulse. Legacy delay keeps its existing stop flushing. Normal note-off permits the room tail to ring. Existing transport has play/stop (no separate pause feature); toggling playback to stop clears tails. Browser AudioContext suspension freezes audio; a new user gesture resumes it. No automatic audio initialization is introduced.

Only `pmg.playback-mix.v1` is added to localStorage (`version`, bounded numeric `volume` and `reverb`). Other song/instrument/cache keys are unchanged. Reset restores .22 volume and zero room effect. Storage unavailable/malformed preferences fall back safely without touching song data.

## Narrow pre-publication self-review

Found and fixed a pending-resume race: an old asynchronous audition could see a newly held identical key ID after navigation and start the old octave before the new resume completed. Pointer and computer-key audition now carry a unique request token; key release, stop and navigation invalidate it, and failed/cancelled preparation cannot trigger a stale note. The regression holds two real-context resume promises, reuses the key at a new octave, resolves the old promise first and checks silence until the current request resolves.

Real OfflineAudioContext comparisons cover the old/new complete default normal and physical output paths, including compressor behavior: sample error 0 in the fixtures. The dry-headroom fixture passes a 1.2 sample unchanged (OfflineAudioContext permits above-full-scale values); this verifies preserving legacy headroom, not recommending that level for hardware output. Peak protection is deliberately enabled only for reverb/boosted settings. Rapid volume automation is tested through the actual output-stage helper; the transition remains smooth and below full scale in the fixture. The default bypass preserves both the ordinary signal and the legacy headroom.

Invalid persisted values (out-of-range, wrong type, unsupported schema version) fall back to the quiet default .22/0 rather than jumping to a maximum; no audio context opens on reload. All normal synth/string/configured/sample voices enter the shared bus; the worklet path enters room.input at its legacy reference level. Both converge at the same master once, followed only by complementary protection paths and the analyser. These are self-review findings, not independent reviewer or iPhone-device verification.
