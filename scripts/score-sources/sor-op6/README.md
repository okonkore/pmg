The LilyPond engraving and symbolic MIDI are vendored here; MIDI hash and conversion statistics are in manifest.json. LilyPond whitespace is normalized. Regenerate with `python3 scripts/import_sor_op6.py` (standard library only).

Conversion preserves MIDI pitches, all three voices, simultaneous notes, tied durations and grace-note timing. Initial MIDI setup silence is removed; the source tempo of quarter note = 88 and 3/4 meter are retained. The score has no repeat sections. Playback applies the existing synth's note gate and release. MIDI contains symbolic note data, not a recording.
